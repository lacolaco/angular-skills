# Angular 17 → 18

Generated from angular/angular @ 28d59e8d6357b6f5015657f06ecd7b543f00aba0

## During the update

- **[Basic]** Make sure that you are using a supported version of node.js before you upgrade your application. Angular v18 supports node.js versions: v18.19.0 and newer
  `v18 node support`

- **[Basic]** In the application's project directory, run `ng update @angular/core@18 @angular/cli@18` to update your application to Angular v18.
  `v18 ng update`

- **[Basic] [Angular Material only]** Run `ng update @angular/material@18`.
  `update @angular/material`

- **[Basic]** Update TypeScript to versions 5.4 or newer.
  `18.0.0 Upgrade TypeScript`

- **[Advanced]** Replace `async` from `@angular/core` with `waitForAsync`.
  `18.0.0: async has been removed, use `waitForAsync` instead`

- **[Advanced]** Remove calls to `matchesElement` because it's now not part of `AnimationDriver`.
  `18.0.0: Deprecated matchesElement method removed from AnimationDriver`

- **[Medium]** Import `StateKey` and `TransferState` from `@angular/core` instead of `@angular/platform-browser`.
  `18.0.0. Use `@angular/core` StateKey and TransferState`

- **[Medium]** Use `includeRequestsWithAuthHeaders: true` in `withHttpTransferCache` to opt-in of caching for HTTP requests that require authorization.
  `18.0.0. Opt-in of caching for HTTP requests with auth headers`

- **[Advanced]** Update the application to remove `isPlatformWorkerUi` and `isPlatformWorkerApp` since they were part of platform WebWorker which is now not part of Angular.
  `18.0.0.REMOVE_OBSOLETE_IS_WORKER`

- **[Medium]** Tests may run additional rounds of change detection to fully reflect test state in the DOM. As a last resort, revert to the old behavior by adding `provideZoneChangeDetection({ignoreChangesOutsideZone: true})` to the TestBed providers.
  `18.0.0.FORCE_ZONE_CHANGE_DETECTION`

- **[Medium]** Remove expressions that write to properties in templates that use `[(ngModel)]`
  `18.0.0: Remove two-way binding expressions in writable bindings`

- **[Advanced]** Remove calls to `Testability` methods `increasePendingRequestCount`, `decreasePendingRequestCount`, and `getPendingRequestCount`. This information is tracked by ZoneJS.
  `18.0.0: Use zones to track pending requests`

- **[Medium]** Move any environment providers that should be available to routed components from the component that defines the `RouterOutlet` to the providers of `bootstrapApplication` or the `Route` config.
  `18.0.0: Move shared providers to the routed component`

- **[Advanced]** When a guard returns a `UrlTree` as a redirect, the redirecting navigation will now use `replaceUrl` if the initial navigation was also using the `replaceUrl` option. If you prefer the previous behavior, configure the redirect using the new `NavigationBehaviorOptions` by returning a `RedirectCommand` with the desired options instead of `UrlTree`.
  `18.0.0 Use RedirectCommand or new NavigationBehaviorOptions`

- **[Advanced]** Remove dependencies of `RESOURCE_CACHE_PROVIDER` since it's no longer part of the Angular runtime.
  `18.0.0: Remove deprecated resource cache providers`

- **[Advanced]** In `@angular/platform-server` now `pathname` is always suffixed with `/` and the default ports for http: and https: respectively are 80 and 443.
  `18.0.0: Update Node.js URL parsing in `ServerPlatformLocation``

- **[Medium]** Provide an absolute `url` instead of using `useAbsoluteUrl` and `baseUrl` from `PlatformConfig`.
  `18.0.0. Use absolute URLs`

- **[Advanced]** Replace the usage of `platformDynamicServer` with `platformServer`. Also, add an `import @angular/compiler`.
  `18.0.0. Switch from `platformDynamicServer` to `platformServer`.`

- **[Medium]** Remove all imports of `ServerTransferStateModule` from your application. It is no longer needed.
  `18.0.0. Remove `ServerTransferStateModule` from app imports`

- **[Advanced]** `Route.redirectTo` can now include a function in addition to a string. Any code which reads `Route` objects directly and expects `redirectTo` to be a string may need to update to account for functions as well.
  `18.0.0. Update `Route.redirectTo` to accept functions`

- **[Advanced]** `Route` guards and resolvers can now return a `RedirectCommand` object in addition to a `UrlTree` and `boolean`. Any code which reads `Route` objects directly and expects only `boolean` or `UrlTree` may need to update to account for `RedirectCommand` as well.
  `18.0.0: Guards can return `RedirectCommand``

- **[Medium]** For any components using `OnPush` change detection, ensure they are properly marked dirty to enable host binding updates.
  `18.0.0: Mark `OnPush` views dirty`

- **[Advanced]** Be aware that newly created views or views marked for check and reattached during change detection are now guaranteed to be refreshed in that same change detection cycle.
  `18.0.0-Refresh-Newly-Created-Views`

- **[Advanced]** After aligning the semantics of `ComponentFixture.whenStable` and `ApplicationRef.isStable`, your tests may wait longer when using `whenStable`.
  `18.0.0: `ComponentFixture.whenStable` matches `ApplicationRef.isStable``

- **[Advanced]** You may experience tests failures if you have tests that rely on change detection execution order when using `ComponentFixture.autoDetect` because it now executes change detection for fixtures within `ApplicationRef.tick`. For example, this will cause test fixture to refresh before any dialogs that it creates whereas this may have been the other way around in the past.
  `18.0.0. `ComponentFixture.autoDetect` behavior more closely matches Application behavior`
