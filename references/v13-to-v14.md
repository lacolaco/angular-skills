# Angular 13 → 14

Generated from angular/angular @ 28d59e8d6357b6f5015657f06ecd7b543f00aba0

## During the update

- **[Basic]** Run `ng update @angular/core@14 @angular/cli@14` which should bring you to version 14 of Angular.
  `v14 ng update`

- **[Basic] [Angular Material only]** Run `ng update @angular/material@14`.
  `update @angular/material`

- **[Basic]** Angular now uses TypeScript 4.6, read more about [any potential breaking changes](https://devblogs.microsoft.com/typescript/announcing-typescript-4-6/).
  `TypeScript 4.6`

- **[Basic]** Make sure you are using [Node 14.15.0 or later](https://www.hostingadvice.com/how-to/update-node-js-latest-version/)
  `v14 node`

- **[Medium]** Form models now require a generic type parameter. For gradual migration you can opt-out using the untyped version of the form model classes.
  `v14 strict forms`

- **[Medium]** Remove `aotSummaries` from `TestBed` since Angular no longer needs them in Ivy.
  `v14 aotSummaries`

- **[Medium] [Angular Material only]** If you are using `MatVerticalStepper` or `MatHorizontalStepper` make sure you switch to `MatStepper`.
  `v14 MatVertical and Horizontal Stepper`

- **[Medium]** Remove headers from JSONP requests. JSONP does not supports headers and if specified the HTTP module will now throw an error rather than ignoring them.
  `v14 JSONP`

- **[Medium]** Resolvers now will take the first emitted value by an observable and after that proceed to navigation to better align with other guards rather than taking the last emitted value.
  `v14 resolvers`

- **[Advanced] [Angular Material only]** The deprecated `angular/cdk/testing/protractor` entry point is now removed.
  `v14 deprecate protractor entry`

- **[Advanced] [Angular Material only]** Make sure you specify `chipInput` of `MatChipInputEvent` because it is now required.
  `v14 chipInput`

- **[Advanced] [Angular Material only]** You need to implement `stateChanges` class member in abstractions using `mixinErrorState` because the mixin no longer provides it.
  `v14 mixinErrorState`

- **[Advanced] [Angular Material only]** Use `CdkStepper.orientation` instead of `CdkStepper._orientation`.
  `v14 CdkStepper orientation`

- **[Advanced] [Angular Material only]** If you are extending or using `CdkStepper` or `MatStepper` in the constructor you should no longer pass the `_document` parameter since it is now removed.
  `v14 CdkStepper and MatStepper`

- **[Advanced] [Angular Material only]** Rename the `mat-list-item-avatar` CSS class to `mat-list-item-with-avatar`.
  `v14 mat-list-item-avatar`

- **[Advanced] [Angular Material only]** Use `MatSelectionListChange.options` rather than `MatSelectionListChange.option`.
  `v14 MatSelectionListChange.option`

- **[Advanced] [Angular Material only]** Use `getChildLoader(MatListItemSection.CONTENT)` rather than `getHarnessLoaderForContent`.
  `v14 getHarnessLoaderForContent`

- **[Advanced] [Angular Material only]** If you are using `MatSelectionList` make sure you pass `_focusMonitor` in its constructor because it is now required. Additionally, this class no longer has `tabIndex` property and a `tabIndex` constructor parameter.
  `v14 MatSelectionList`

- **[Advanced]** Update `initialNavigation: 'enabled'` to `initialNavigation: 'enabledBlocking'`.
  `v14 initialNavigation`

- **[Advanced]** If you are defining routes with `pathMatch`, you may have to cast it to `Route` or `Routes` explicitly. `Route.pathMatch` is no longer compatible with `string` type.
  `v14 Route.pathMatch`

- **[Advanced]** The promise returned by `LoadChildrenCallback` now has a stricter type parameter `Type<any>|NgModuleFactory<any>` rather than `any`.
  `v14 stricter LoadChildrenCallback`

- **[Advanced]** The router does no longer schedule redirect navigation within a `setTimeout`. Make sure your tests do not rely on this behavior.
  `v14 router scheduling`

- **[Advanced]** Implementing the `LocationStrategy` interface now requires definition of `getState()`.
  `v14 LocationStrategy`

- **[Advanced]** Sending `+` as part of a query no longer requires workarounds since `+` no longer sends a space.
  `v14 http queries`

- **[Advanced]** Implementing `AnimationDriver` now requires the `getParentElement` method.
  `v14 AnimationDriver.getParentElement`

- **[Advanced]** Invalid route configurations of lazy-loaded modules will now throw an error rather than being ignored.
  `v14 invalid config`

- **[Advanced]** Remove the `resolver` from `RouterOutletContract.activateWith` function and the `resolver` from `OutletContext` class since factory resolvers are no longer needed.
  `v14 router resolver`

- **[Advanced]** `Router.initialUrl` accepts only `UrlTree` to prevent a misuse of the API by assigning a `string` value.
  `v14 initialUrl`
