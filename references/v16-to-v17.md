# Angular 16 → 17

Generated from angular/angular @ 28d59e8d6357b6f5015657f06ecd7b543f00aba0

## During the update

- **[Basic]** Make sure that you are using a supported version of node.js before you upgrade your application. Angular v17 supports node.js versions: v18.13.0 and newer
  `v17 node support`

- **[Basic]** Make sure that you are using a supported version of TypeScript before you upgrade your application. Angular v17 supports TypeScript version 5.2 or later.
  `v17 ts support`

- **[Basic]** Make sure that you are using a supported version of Zone.js before you upgrade your application. Angular v17 supports Zone.js version 0.14.x or later.
  `v17 zone.js support`

- **[Basic]** In the application's project directory, run `ng update @angular/core@17 @angular/cli@17` to update your application to Angular v17.
  `v17 ng update`

- **[Basic] [Angular Material only]** Run `ng update @angular/material@17`.
  `update @angular/material`

- **[Medium]** Angular now automatically removes styles of destroyed components, which may impact your existing apps in cases you rely on leaked styles. To change this update the value of the `REMOVE_STYLES_ON_COMPONENT_DESTROY` provider to `false`.
  `v17 style removal`

- **[Basic]** Make sure you configure `setupTestingRouter`, `canceledNavigationResolution`, `paramsInheritanceStrategy`, `titleStrategy`, `urlUpdateStrategy`, `urlHandlingStrategy`, and `malformedUriErrorHandler` in `provideRouter` or `RouterModule.forRoot` since these properties are now not part of the `Router`'s public API
  `v17 router removals`

- **[Advanced]** For dynamically instantiated components we now execute `ngDoCheck` during change detection if the component is marked as dirty. You may need to update your tests or logic within `ngDoCheck` for dynamically instantiated components.
  `v17 ngDoCheck dynamic components`

- **[Medium]** Handle URL parsing errors in the `UrlSerializer.parse` instead of `malformedUriErrorHandler` because it's now part of the public API surface.
  `v17 malformedUriErrorHandler`

- **[Medium]** Change Zone.js deep imports like `zone.js/bundles/zone-testing.js` and `zone.js/dist/zone` to `zone.js` and `zone.js/testing`.
  `v17 zone deep imports`

- **[Advanced]** You may need to adjust your router configuration to prevent infinite redirects after absolute redirects. In v17 we no longer prevent additional redirects after absolute redirects.
  `v17 absolute redirects`

- **[Medium]** Change references to `AnimationDriver.NOOP` to use `NoopAnimationDriver` because `AnimationDriver.NOOP` is now deprecated.
  `v17 AnimationDriver`

- **[Basic]** You may need to adjust the equality check for `NgSwitch` because now it defaults to stricter check with `===` instead of `==`. Angular will log a warning message for the usages where you'd need to provide an adjustment.
  `v17 switch strictness`

- **[Advanced]** Use `update` instead of `mutate` in Angular Signals. For example `items.mutate(itemsArray => itemsArray.push(newItem));` will now be `items.update(itemsArray => [itemsArray, …newItem]);`
  `v17 mutate in signals`

- **[Medium]** To disable hydration use `ngSkipHydration` or remove the `provideClientHydration` call from the provider list since `withNoDomReuse` is no longer part of the public API.
  `v17 withNoDomReuse`

- **[Basic]** If you want the child routes of `loadComponent` routes to inherit data from their parent specify the `paramsInheritanceStrategy` to `always`, which in v17 is now set to `emptyOnly`.
  `v17 paramsInheritanceStrategy`
